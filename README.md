## Overview

**LLM4MG** is a large-language-model-based framework for generating fine-grained wireless channel multipath information from multi-modal sensory observations under the **Synesthesia of Machines (SoM)** paradigm.

Focusing on sixth-generation (**6G**) vehicle-to-infrastructure (**V2I**) communications, LLM4MG learns the complex mapping between the physical propagation environment and channel multipath characteristics. It takes synchronized sensing data from the transmitter and receiver—including RGB-D images, LiDAR point clouds, and millimeter-wave radar point clouds—and predicts:

- line-of-sight (**LoS**) or non-line-of-sight (**NLoS**) status;
- multipath power values; 
- multipath delay values.

The framework adapts **LLaMA 3.2** to a wireless channel generation task through multi-modal feature alignment, propagation-aware prompt engineering, and low-rank adaptation.
